# Chirpy

A Twitter/X-like RESTful microblogging backend server built with **Go (Golang)**, **PostgreSQL**, and **sqlc**, inspired by the Boot.dev backend curriculum.

Chirpy supports user authentication (Argon2id password hashing, JWT access tokens, and persistent Refresh Tokens), profanity filtering, Chirp CRUD operations with author filtering and in-memory sorting, webhook handling for subscription upgrades ("Chirpy Red"), and administrative metric endpoints.

---

## Features

- **User Management & Authentication**:
  - Secure password hashing using **Argon2id**.
  - **JWT (JSON Web Tokens)** for stateless access authorization.
  - **Refresh Tokens** stored in PostgreSQL with expiration and revocation support.
  - Authenticated profile updates (email and password).
- **Chirps (Posts)**:
  - Create, read, and delete chirps (up to 140 characters).
  - Profanity censorship: automatically replaces forbidden words with `****`.
  - Author-based ownership validation (only authors can delete their chirps).
  - Query filtering by `author_id`.
  - Configurable sorting by creation date (`sort=asc` or `sort=desc`).
- **Webhooks & Subscriptions (Chirpy Red)**:
  - Integration with mock payment provider (Polka).
  - Webhook endpoint authenticated via `ApiKey` header to upgrade users to Chirpy Red status.
- **Developer & Admin Operations**:
  - In-memory file server hit metrics counter with HTML dashboard (`/admin/metrics`).
  - Dev-only database reset endpoint (`/admin/reset`).
  - Static file hosting (`/app/`).
- **Data Layer**:
  - Type-safe, high-performance database queries generated by **sqlc**.
  - Schema migrations managed by **goose**.

## Getting Started

### Prerequisites

- [Go](https://go.dev/doc/install) (1.22 or newer)
- [PostgreSQL](https://www.postgresql.org/download/) installed and running
- [goose](https://github.com/pressly/goose) (for database migrations)
- [sqlc](https://sqlc.dev/) (optional, if modifying SQL queries)

### 1. Clone the Repository

```bash
git clone git@github.com:Xavier-Hsiao/ChirpyGo.git
cd ChirpyGo
```

### 2. Configure Environment Variables

Create a `.env` file in the root directory:

```env
DB_URL="postgres://username:password@localhost:5432/chirpy?sslmode=disable"
PLATFORM="dev"
JWT_SECRET="your-super-secret-jwt-key"
POLKA_KEY="your-polka-api-key"
```

### 3. Run Database Migrations

Run all migrations up to the latest version:

```bash
goose -dir sql/schema postgres "$DB_URL" up
```

### 4. Build and Run the Server

```bash
go run .
```

By default, the server listens on `http://localhost:8080`.

## API Endpoints

### Public & Health Check
| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/healthz` | Health check (returns `200 OK`) |
| `GET` | `/app/*` | Static file server |

### Authentication & Users
| Method | Endpoint | Auth | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/users` | None | Register a new user |
| `POST` | `/api/login` | None | Authenticate user, returns Access Token & Refresh Token |
| `POST` | `/api/refresh` | Bearer (Refresh Token) | Issue a new 1-hour Access Token |
| `POST` | `/api/revoke` | Bearer (Refresh Token) | Revoke a refresh token |
| `PUT` | `/api/users` | Bearer (JWT) | Update user email and/or password |

### Chirps
| Method | Endpoint | Auth | Description |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/chirps` | None | List chirps. Supports query params: `?author_id=<uuid>` and `?sort=asc\|desc` |
| `GET` | `/api/chirps/{chirpID}` | None | Retrieve a single chirp by ID |
| `POST` | `/api/chirps` | Bearer (JWT) | Create a new chirp (max 140 chars) |
| `DELETE`| `/api/chirps/{chirpID}` | Bearer (JWT) | Delete a chirp (author only) |

### Webhooks
| Method | Endpoint | Auth | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/polka/webhooks` | `ApiKey <POLKA_KEY>` | Upgrade user to Chirpy Red (`user.upgraded` event) |

### Admin & Metrics
| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/admin/metrics` | View hits metric dashboard (HTML) |
| `POST` | `/admin/reset` | Reset metrics & truncate database (enabled only when `PLATFORM=dev`) |
